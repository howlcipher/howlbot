HowlBot

HowlBot is an event-driven Discord operations bot and external HowlFrame dogfooding application. Discord users may propose actions, but trusted identity evidence and deterministic HowlFrame policy decide what the system is authorized to do.

Architecture & Security Boundary

MESSAGE ≠ AUTHORITY

Discord input
   ↓
trusted identity evidence
   ↓
HowlFrame policy
   ↓
decision
   ↓
bounded effect

Relationship to HowlFrame

HowlBot acts as a host adapter. It handles the Discord protocol, builds normalized identity evidence, and submits it to HowlFrame. HowlFrame executes the deterministic policy to yield an ALLOW, DENY, or REQUIRE_APPROVAL decision.

Commands

  • /howl status - System check
  • /howl policy - Show current policy constraints
  • /howl history - View audit trail
  • /repo status - Repository status
  • /repo release - Propose release (requires approval)
  • /repo approve <id> - Approve operation

Setup

See the README in the repository for detailed configuration instructions, requiring a Discord bot token and appropriate configured roles.
